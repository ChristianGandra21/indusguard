## Regra de atualização

Uma funcionalidade só deve aparecer como concluída quando existir código e teste correspondente.
Ideias futuras ficam identificadas como roadmap. Isso evita que a documentação prometa um executor,
agente ou frontend que ainda não está disponível no repositório.
