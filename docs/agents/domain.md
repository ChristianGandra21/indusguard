# Domain docs

O IndusGuard utiliza documentação de domínio single-context.

## Antes de explorar

As engineering skills devem consultar, quando existirem:

- `CONTEXT.md` na raiz;
- ADRs relevantes em `docs/adr/`.

A ausência desses arquivos não é um erro. Eles serão criados somente quando decisões ou conceitos
de domínio precisarem ser registrados.

## Vocabulário

Issues, especificações, testes e propostas devem usar os termos definidos em `CONTEXT.md`.

Quando um termo necessário não estiver documentado, a skill deve avaliar se existe uma lacuna de
domínio antes de inventar um novo nome.

## ADRs

Conflitos com ADRs existentes devem ser apresentados explicitamente, em vez de sobrescrever
silenciosamente uma decisão anterior.
