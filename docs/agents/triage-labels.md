# Triage labels

| Papel canônico | Label no GitHub | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Precisa ser avaliada pelo mantenedor. |
| `needs-info` | `needs-info` | Aguarda informações adicionais. |
| `ready-for-agent` | `ready-for-agent` | Especificação completa e pronta para um agente. |
| `ready-for-human` | `ready-for-human` | Exige implementação ou decisão humana. |
| `wontfix` | `wontfix` | Não será executada. |

Quando uma skill mencionar um papel canônico, deve usar o label correspondente desta tabela.
