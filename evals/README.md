# Avaliações

Este diretório receberá o benchmark `prompt_only` × `guarded`. Os gabaritos fornecidos no desafio
ficarão isolados do runtime e não serão copiados para imagens de produção.

O runner deverá consumir traces somente depois da execução do agente. A separação impede que
trajetórias esperadas ou respostas de referência contaminem o planejamento do modelo.

Estado atual: diretório reservado; ainda não há runner nem resultados publicados.
