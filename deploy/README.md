# Deployment

Manifestos de container, Render, banco e observabilidade serão adicionados quando o runtime do
agente estiver implementado. O modo público continuará usando `INDUSGUARD_EXECUTION_MODE=simulate`.

O objetivo desta pasta é concentrar Dockerfiles e configuração de infraestrutura sem misturar
detalhes de um provedor com o código da aplicação. Nenhum deployment público existe nesta etapa.
